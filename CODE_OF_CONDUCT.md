# Code of conduct

Huntaway follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good faith, and keep discussion about the work.

For a conduct concern about GitHub content, open that content's menu, choose **Report content**, and select
**Report to repository admins** when available. Reports to GitHub Support go to GitHub, not the project maintainers.
Do not put private details in a public issue. See [GitHub's reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

The project takes conduct reports through GitHub only; there is no conduct email address. This is separate from
private security-vulnerability reporting (see [SECURITY.md](SECURITY.md)).
